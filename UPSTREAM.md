# Upstream and scope

DeepSeek Harness Ultimate is an independent profile for
[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness), developed
by DeepSeek AI. It is not affiliated with or endorsed by DeepSeek AI.

The profile does not fork, modify, or relicense the upstream projects. It pins
upstream Git repositories in `profile/manifest.json` and asks the local
installer to fetch them. Each upstream project remains governed by its own
license, copyright, and contribution rules.

The native macOS shell is maintained separately in
[deepseek-harness-macos-app](https://github.com/18126295767-cell/deepseek-harness-macos-app).
This Ultimate repository does not include that shell, third-party source, or a
prebuilt dependency tree.
